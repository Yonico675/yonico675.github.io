Projet : Rébus

Description

Ce projet consistait à créer un jeu de Rébus où il fallait deviner des expressions à partir d'images.

Exemple de rébus : Pas + Rat + Pluie = "Parapluie".

Technologies utilisées : HTML, CSS, JavaScript.

Fonctionnalités

  • Affichage aléatoire de rébus.
  • Système de vérification des réponses.
  • Compteur de score.

Compétences développées

HTML/CSS JavaScript Logique de jeu
